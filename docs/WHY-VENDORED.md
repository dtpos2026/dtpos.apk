# Why the Capacitor runtime is committed here

## The error this repository exists to prevent

```
Could not read script '...\android\Customer\capacitor-cordova-android-plugins\
cordova.variables.gradle' as it does not exist.
```

That is not a corrupt download. `settings.gradle` includes the
`capacitor-cordova-android-plugins` project unconditionally:

```groovy
include ':capacitor-cordova-android-plugins'
```

while Capacitor's own `.gitignore` **excludes that whole directory**, because
`npx cap sync` regenerates it from `node_modules`. So it is absent in every
fresh clone and every downloaded zip, and Gradle stops before compiling a line.

The same is true of `app/src/main/assets/public/` — the web bundle — and of
`capacitor.settings.gradle`, which points at paths inside `node_modules`:

```groovy
project(':capacitor-android').projectDir = new File('../../node_modules/@capacitor/android/capacitor')
```

A checkout with no `node_modules` cannot resolve that at all.

## What was done about it

This repository's promise is that a restaurant's APK can be built with nothing
but Android Studio. So everything Gradle reads is committed:

| Committed here | Normally |
|---|---|
| `libs/capacitor/` | `node_modules/@capacitor/android/capacitor` |
| `libs/capacitor-push-notifications/` | `node_modules/@capacitor/push-notifications/android` |
| `Customer/capacitor-cordova-android-plugins/` | generated by `cap sync` |
| `Customer/app/src/main/assets/public/` | generated by `cap sync` |
| `*/app/src/main/assets/capacitor.config.json` | generated by `cap sync` |

and each app's `capacitor.settings.gradle` points at `../libs` instead of
`../../node_modules`.

The root `.gitignore` is written to keep them, and explains why. Do not "tidy"
it by copying Capacitor's default ignores back in — that is precisely the bug.

## Keeping the vendored runtime current

`libs/` is a copy of two published packages. To move to a newer Capacitor, copy
them again from a POS checkout that has installed it:

```bash
cp -r node_modules/@capacitor/android/capacitor            libs/capacitor
cp -r node_modules/@capacitor/push-notifications/android   libs/capacitor-push-notifications
```

and check that `Customer/variables.gradle` still lists the versions that release
expects. Nothing else in this repository needs to change.
